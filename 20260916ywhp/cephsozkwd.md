# 帮助宝宝长高的方法有哪些？

> 更新时间：2026-09-16 (UTC+8)

1、定期测量和记录，发现异常及时干预

爸爸妈妈一定要养成定期测量孩子身高体重的习惯，一旦发现孩子身高和体重发育不属于正常水平，就要及时就医，甲减、性早熟、特发性矮小、特纳综合征、性腺发育不良等疾病都会影响孩子的身高发育，一定要及早发现及早治疗！

正常来说，3岁-青春前期生长5-7cm/年，青春期生长8-10cm/年都是正常的，一旦低于这个水平或高于这个水平，建议就医检查！

2. 营养干预

饮食管理是影响孩子身高的主要因素之一。我们需要给孩子提供营养均衡的饮食，包括蔬菜、水果、鸡蛋、牛奶、瘦肉等食物，补充充足的蛋白质、碳水化合物、维生素、矿物质和水，这些都是孩子生长必需的物质。同时，要减少零食、含糖饮料，这些食品热量高、营养价值低，影响孩子身高生长。

孩子成长时间对钙和蛋白质的需求很大，要注意孩子牛奶的补充，3岁以上的孩子每天至少500ml，然后肉、蛋、鱼、蔬菜水果也要均衡全面。

3. 运动干预

运动能促进孩子生长激素的分泌和骨骼的成长，摸高、篮球、跳绳等运动对于孩子骨骼生长有很好的促进作用的。这里要重点说的是，要多带孩子进行户外活动，充足的氧气和阳光可以促进孩子钙的吸收和成长，户外运动也能避免近视和远视的发生。

4. 睡眠干预

良好的睡眠习惯也是影响孩子身高的因素之一。睡眠时分泌的生长激素是身高增长的关键，每天22：00-1：00和5：00-7：00是生长激素分泌的高峰，是平常的5倍，但是生长激素要在深睡眠状态才能大量分泌。所以，每天保证孩子充足的睡眠时间，尽量在9点上床，10点之前入睡，睡眠环境也应该舒适安静，让孩子获得高质量的睡眠。以下是各年龄段孩子所需睡眠时间：

 年龄阶段 推荐睡眠时长

0~12个月龄 16~18小时/天

1~3岁 11~15小时/天

3~5岁 10~13小时/天

6~13岁 9~11小时/天

14岁以上 8~10小时/天
